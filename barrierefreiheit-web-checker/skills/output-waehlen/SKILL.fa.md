# انتخاب محصول

## وضعیت کاربرد

این هفته های خروجی برای **Barrierefreiheit Web Checker** تعیین می کند که آیا یادداشت، درخواست، اسناد، جدول، چراغ خطر، لیست سوالات یا نامه مشتری قدم بعدی مناسب است.

## نقشه تخصصی این افزونه

- `abnahme-formular-portal-und-einreichung` - دریافت فورمه پورتال و ارسال
- `agentur-abnahme-vergabe` - آژانس خرید و فروش
- `audit-barrierefreiheits-bfsg` - حسابرسی دسترسی
- `automatisierter-audit-axe-lighthouse` - آدايت هاي خودکشي AXE Lighthouse
- `barrierefreiheit-fehlerkatalog` - دسترسی خطای فهرست
- `barrierefreiheits-erstpruefung-und-mandatsziel` - اولین بررسی دسترسی و هدف مأموریت
- `bf-kanzleiwebsite-konkret` - وب سایت دفترچه
- `bf-kiosk-selbstbedienung-mediendienste` - BF کیوسک خدمات رسانه ای
- `bf-mediendienste-untertitel-spezial` - خدمات رسانه ای زیرنویس ویژه
- `bf-pdf-schriftsaetze-versand` - BF PDF ارسال نامه
- `bfsg-tatbestand-beweis-und-belege` - نمونه: شواهد و مدارک
- `bfsg-zeitleiste-ecommerce-checkout-en301549` - برای مثال، چک کردن زمان برقی تجارت الکترونیک En301549
- `bfsgv-schulung-fristennotiz-agentur-abnahme` - به عنوان مثال آموزش و پرورش نوتیفکیشن زمان پذیرش
- `anschluss-routing` - رویتینگ اتصال
- `dokumente-intake` - اسناد دخول

## مسیر کار

- نوع نتیجه را تعیین کنید: ارسال نامه به اپراتورهای وب سایت، ماموران دسترسی فدرال/ملتی، اداره حل و فصل BFSG، نظارت بازار، یادداشت مشتری، گزارش ریسک، طرح قرارداد، قالب تصمیم گیری، تصریح مقامات - چه چیزی واقعاً برای مشتریان نیاز دارد؟
- تنظیم فرمت های لازم: Tenor / درخواست / دلیل (دلیل ادعای، پرونده اعمال ، زیرنویس، نتیجه) ؛ انجام معیارهای مشخص در آزادی مانع وب سایت (BFSG, BITV 2.0, EU 2016/2102, EAA-RL 2019/882, WCAG 2.1 / 2.2 (AA), DIN EN 301 549).
- وضوح مخاطب: زبان، عمق جزئیات و پیشگیری قانونی را در نظر بگیرید؛ برای مشتری بدون آموزش کامل خلاصه ی متن واضح ارائه دهید.
- برنامه های ساخت و ساز (تاریخی، موضوعی، K- و B-پلان) ؛ اشاره ها را به صورت تمیز نشان دهید.
- نوتیزه های منبع و به صورت نقل قولی را تضمین کنید؛ نقاط باز و فرضیه ها را بطور صریح چنین نشان دهید.
