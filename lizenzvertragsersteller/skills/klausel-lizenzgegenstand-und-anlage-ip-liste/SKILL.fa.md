# بند موضوع مجوز + ضمیمه A

## عملکرد

در این مورد، Praezision به صورت کلی می گوید: کسی که موضوع مجوز را مبهم نگه دارد (همه ی IP های متعلق به صاحب مجوز) ، بعداً خطر اختلاف مربوط به تعلق است.

## تکنیک های پیش بینی برای هر نوع IP

| نوع IP | شناسایی |
|---|---|
| حق اشغال (کار) | عنوان، کفش ها، سال تولید کفشها |
| نرم افزار | URL مخزن، هش تعهد (به عنوان مثال SHA) ، نام بخش، نسخه ساخت |
| ثبت اختراع | -آره .Nr. + تاریخ ggf. شماره ادعای |
| برند | -آره .Nr., علامت کلمه/تصاویر, کلاس های نیزه |
| طراحی | -آره .Nr., توضیحات, مناطق حفاظت شده |
| نمونه های استفاده | -آره .Nr., تاریخ |
| راز تجاری | نام + هاش سیستم + شماره نسخه |
| دامنه | دامنه + ثبت کننده |

## ماده ساختمانی بند

> **$2 مورد مجوز*
>
> (1) موضوع مجوز حقوق حفاظت شده در ضمیمه A** و دانش آموزانی است که به عنوان تعریف شده در این ضمیمہ (به طور مشترک "موضوع ثبت نام")
>
> (2) هر گونه تمدیدات، ثبت نام های اختراع یا درخواست های بعدی در مورد این اختراع وجود دارد [JA / NEIN] در صورت ج: به روز رسانی سالیانه از آلاسی A
>
> (3) ضمیمه ای از این قرارداد به صورت پیوسته تشکیل می دهد.

## روال چک قبل از امضا

1. از ثبت حقوق حفاظت در صورت زنده (DPMA، EUIPO, EPA)
2. Whois برای دامنه ها
3. هش ذخیره سازی در نرم افزار (به عنوان مثال: `git log -1 --pretty="%H"`)
4. هاش سیستم در مورد دانش (SHA-256 مجموعه اسناد)
5. ثبت حقوق حفاظت
