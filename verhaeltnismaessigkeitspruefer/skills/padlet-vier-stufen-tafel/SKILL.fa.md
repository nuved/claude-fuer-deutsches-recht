# نه فقط پیشنهاد، بلکه ساخت تابلوهای واقعی

> **در مورد یک پادلی واقعی کار کنید نه فقط در مورد توصیف.** اگر هیچ از راه های زیر جواب ندهد، به طور صادقانه نام داده می شود و مشخصاً سوال شده که کدام مسیر را انتخاب کنیم.

## راه 1: پادلت عمومی API v1 (ترجیح شده)

پادلت یک API رسمی REST را اجرا می کند. شرط آن اشتراک پولی از PADLET و کلید API در داشبورد (سیستم ها → حساب شخصی → توسعه دهنده → تولید) است.

**حالت ها:**

1. **آفرین کلید API* * بررسی اینکه آیا از میان اعتبارنامه های سفارشی خود ثبت شده است `padlet.com` در واقع، اگر این اتفاق افتاده باشد، `api_credentials=["custom-cred:padlet.com"]` اگر نه، فقط یک بار در صفحه ی بالای کامپیوتر را زیر تنظیمات → اعتباری های سفارشی → اضافه کنید.
2. **برنامه را ایجاد کنید.** در حال حاضر API عمومی v1 هنوز تمام برگه ها را قرار نمی دهد، بلکه فقط پست هایی روی بوردهای موجود می گذارد. بنابراین یک شلف خالی با چهار ستون باید از قبل وجود داشته باشد. اگر هیچ کدام دیگر نباشد: در صفحه اصلی خود پادلت جدید → قالب "شرف" → نامگذاری چهار کالم ("مقصد قانونی"، "ملازمت،" "ضروریتی"، "مناسبیت") → کاپی کردن آی دی Board از URL
3. ** ایجاد پست ها** از طریق نقطه پایان `POST /api/1/boards/{boardId}/posts`هر کارت یک تماس است. `subject`, `body`, `section` (= نام کالم یا ID کالم) رنگ در `color`-آرک یا Tag
4. **به بخش اختصاص دهید.** در API، کالم ها به عنوان "Sections" نامیده می شوند. `GET /api/1/boards/{boardId}` از `sections`-آری
5. **پاسخ بررسی کنید.** در HTTP 201، پیامی که به شما داده شده است را نگه دارید تا تغییرات یا حذف ممکن باشد.

**برای مثال به عنوان یک "کیرل" (api_credentials از تنظیم سرنخ مجوز استفاده می کند):

```
POST https://api.padlet.com/api/1/boards/{boardId}/posts
Content-Type: application/json

{
  "subject": "Stufe 1 / A1",
  "body": "Vorgetragener Zweck: oeffentliche Sicherheit und Marktentzerrung",
  "sectionId": "<section-id-aus-board-get>",
  "color": "green"
}
```

## راه دوم: مرورگر وارد شده (فالوگ بدون کلید API)

اگر کلید API موجود نباشد یا اشتراک پادلی وجود نداشته باشد، از طریق جلسه مرورگر وارد شده پیدلت را ایجاد کنید.

**حالت ها:**

1. `browser_task` با `use_local_browser.local=true` و `url=https://padlet.com` شروع کنید.
2. در داشبورد پادلت "Make a padlet" -> Format "Shelf" -> عنوان "Path proportionality check".
3. چهار کالم را نامگذاری کنید: "1 · هدف قانونی"، "2 · مناسب" "3 · ضرورییت،" "4 · مناسب".
4. هر مرحله با دکمه اضافه، نقشه ها را روی منوی کارت قرار دهید.
5. در نظر گرفتن "رابط مخفی" یا "خصوصی".
6. لینک های مشترک را از پنیل اشتراک بگذارید.

مسیر مرورگر آهسته تر است، اما قابل مشاهده و درک می شود. اگر یک عمل تایید مانند انتشار در حال انجام باشد باید از قبل به عنوان پیام تأییدشده در کاربری براوزر ذکر گردد.

## راه سوم: ساخت دستی با نشان دادن نقشه

اگر نه کلید API و نه مرورگر وارد شده در دسترس باشد، **کـن** شلف بورد خود را به ارمغان می آورد.

1. ** دستورالعمل های مشخصی برای نصب هیئت قفسه خالی در پرچم بالای پدلت.
2. **محتویات نقشه به عنوان بلاک مارک داون**، با رنگ های چراغ و منابع مرتب شده است.

```
Spalte: 1 · Legitimer Zweck
Farbe: gruen
Titel: A1
Inhalt: oeffentliche Sicherheit und Marktentzerrung; Schranke einfach
Quellen: Apotheken-Urteil BVerfGE 7, 377
```

3. ** یادآوری** به کاربر: واردات CSV پادلی برای پست ها وجود ندارد؛ عملکرد رسمی کیف پشتی فقط تمام پدلات را از یک نمونه ی پادلیت به دیگری وارد می کند.

## ساختار کالم ها و نقشه

### کالم 1 · هدف مشروع
- کارت ۱: هدف مطرح شده
- نقشه دوم: نوع حریم (ساده، واجد شرایط و قانون اساسی)
- نقشه سوم: قابلیت حمل از مواد قانونی
- نقشه 4: بخش های ممنوعه (معمولی، حمایت از مردم و تبعیض).

### کالم 2 · مناسب بودن
- نقشه ی اول: مکانیسم کار کردن، ابزار به هدف.
- نقشه دوم: شواهد تجربی یا پیش بینی.
- نقشه سوم: ضخامت کنترل (شهادت، نمایندگی و بررسی شدید).

### کالم 3 · ضرورت
- نقشه ی اول: گزینه ی یک (کارایی، شدت عمل).
- نقشه دوم: گزینه دو (کارایی، شدت عمل).
- نقشه 3: گزینه 3 (کارایی، شدت عمل)
- نقشه چهارم: دلیل اینکه چرا روش مورد نظر نرم ترین است.

### ستون 4 · مناسب بودن
- نقشه ی اول: صفحه مداخله (درجات، شدت، مدت زمان و برگشت پذیری).
- نقشه دوم: صفحه هدف (مرتب، احتمال و اندازه آسیب).
- نقشه 3: تضمین های قانونی و مکانیسمهای تعویض.
- نقشه 4: محدودیت های مطلق (مردم، ارزش و حداقل زندگی).
- نقشه پنجم: رتبه بندی کل

## رنگ های روشن

- گروین: سطح بدون مشکل
- * زرد*: سطح نیاز به ارزیابی دارد
- ** قرمز**: مرحله شکست خورده یا متناقض است.

## پیش بینی ASCII به عنوان یک همراه (نه جایگزین)

پیش بینی ASCII به صورت ** افزون** در پادلت واقعی منتشر می شود تا وضعیت را از طریق اینترنت قابل خواندن باشد:

```
+ Spalte 1 (Zweck)  + Spalte 2 (Geeignet) + Spalte 3 (Erforderlich) + Spalte 4 (Angemessen) +
| A1 gruen          | A1 gruen            | A1 rot                  | A1 rot                |
| A2 gelb           | A2 gelb             | A2 gelb                 | A2 gelb               |
| A3 gruen          | A3 gruen            | A3 gruen                | A3 gruen              |
+-------------------+---------------------+-------------------------+-----------------------+
```
