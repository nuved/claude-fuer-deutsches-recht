# چطور می توانم به دادگاه رسمی نامه بنویسم؟

## این در مورد چی است؟

دادگاه یک سازمان است که دارای کنوانسیون های خاص خود می باشد. شما نیازی به نوشتن قانونی ندارید - اما برخی از فرم ها باعث افزایش اعتماد و جلوگیری از پرسش می شوند. این مهارت نشان دهنده استدلال مناسب، عناصر سرخط نامه و فرمولهای بی اعتنایی نهایی هستند.

## چه وقت به این مهارت نیاز داری؟

- شما در دادگاه رسمی پرونده ای می نویسید.
- شما مطمئن نیستید که چطور به دادگاه مراجعه کنید.
- شما می خواهید به شکل صحیح سند را انتخاب کنید.

## مفاهیم تخصصی (به طور خلاصه توضیح داده شده)

- **نگر پرونده**: شماره مشخصی از یک روش، مثلاً "5 C 234/25".
- **درخواست نامه**: هر گونه درخواست نوشته شده ای که در دادگاه ارائه می شود.
- ** دفتر کار**: بوئرو دادگاه که نامه می گیرد.

## مبانی قانونی

- **§ 130 ZPO** - محتوای یک عبارت.
- **§ 130a ZPO** - سند الکترونیکی
- **§ 253 ZPO** - فرم شکایت

## راهنمای قدم به گام

### مرحله اول - سر نامه

در بالا سمت چپ، اطلاعات شما:

```
[Vorname Nachname]
[Strasse Hausnummer]
[PLZ Ort]

Telefon: [optional]
Email: [optional]
```

در مورد افراد حقوقی شرکت + نماینده

### مرحله 2 - تاریخ و مکان

در بالا سمت راست یا زیر نام شما:

```
Musterstadt, 27. Mai 2026
```

### مرحله 3 - دریافت کننده

```
An das
Amtsgericht Musterstadt
- Geschaeftsstelle der Zivilabteilung -
Musterstrasse 1
12345 Musterstadt
```

در مورد نشانه های شناخته شده: بخش خاصی را نشان دهید، مثلا "آفتون C 5".

### مرحله ۴ - خط موضوعی با نشانه های پرونده

```
Betreff: Aktenzeichen [AZ]
 Rechtsstreit Mustermann ./. Beispielmann
 wegen [Streitgegenstand]
```

در مورد اولین شکایت (حتی هیچ سندی نیست):

```
Betreff: Klage
 Mustermann ./. Beispielmann
 wegen [Streitgegenstand]
```

نکته عملی: "./." (دستگاه نقطه-قطر) به معنای "در مقابل".

### مرحله پنجم - سخنراني

```
Sehr geehrte Damen und Herren,
```

یا در مورد یک قاضی مشخص (در ندرت لازم است):

```
Sehr geehrter Herr Vorsitzender,
```

به طور کلی، "خانمها و آقایان" همیشه درست است.

### مرحله 6 - نرخ باز کردن

اولین مطلب (دعوی):

```
in der Sache [Name] ./. [Name] erhebe ich
hiermit Klage und stelle folgende Antraege:
```

نوشته های دیگر:

```
in obiger Sache nehme ich wie folgt Stellung:
```

یا

```
in obiger Sache repliziere ich auf die
Klageerwiderung vom [Datum] wie folgt:
```

### مرحله هفتم - محتوای آن

سخنرانی واقعی، ارائه شواهد و درخواست ها - همانطور که در سایر مهارت های ذکر شده است.

### مرحله ۸ - فرمول نهایی

```
Mit freundlichen Gruessen

[Unterschrift]

[Name in Druckbuchstaben]
```

در صورت ارسال الکترونیکی از طریق MJP: یک امضا ساده برای ارتباط با مسیر امن انتقال کافی است (§ 130a III ZPO).

### مرحله 9 - تجهیزات

در آخر:

```
Anlagen:
K1 — [Bezeichnung]
K2 — [Bezeichnung]
...
```

### مرحله 10 - لیست دریافت کنندگان

در صورت ارسال به چند نفر (در دادگاه + متهم): توزیع کنندگان زیر:

```
Verteiler:
1 x Original Amtsgericht Musterstadt
1 x Abschrift Beklagter
1 x Kopie zu meinen Akten
```

## آنچه که باید به ویژه توجه کنید

- شکل او، شکل مسئولیت
- **هیچ تحقیر**، حتی اگر به طور قانونی از بدن استفاده شود.
- **هیچ زباني** ("اون منو گول زده" - درست بنویسيد)
- ** همیشه علامت های پرونده را به صورت مشخصی بیان کنید** وقتی که آن ها در اختیار دارید - وگرنه ممکن است خط نوشته شما در فایل مناسب نباشد.

### مرحله 11 - درخواست به خود دادگاه

در دادگاه های محلی، یک قاضی به طور جداگانه تصمیم می گیرد و نه اتاق (خزانۀ نام "کُرَبِ" است که در دیوان ها استفاده میشود). AG عبارت "قضیه" یا "محکمه ی خصوصی"، نه اینکه "پرداخت".

مثال:

```
Ich bitte das Gericht, den Beweisantrag zu beruecksichtigen.
```

یا

```
Ich bitte den Einzelrichter, ...
```

## خطاهای رایج

- "سلام، قاضی من در مورد ..."
- "آقا شمیت" - البته شخصاً، اما اگر مطمئن نیستید که قاضی شمیدت مسئول است بهتره خنثی بشین.
- "دستور ها را از دست ندهید، دادگاه می داند".
- "به یک نامه چند چیز را مخلوط کنید".
